# KahfiEdu

## Deskripsi Aplikasi
**KahfiEdu** adalah aplikasi bimbingan belajar (Bimbel) BTQ berbasis web yang dirancang untuk mendukung layanan pendidikan **Kahfi Education**.  
Aplikasi ini memfasilitasi:
- Pendaftaran siswa  
- Manajemen pembayaran  
- Absensi  
- Laporan perkembangan belajar  

Seluruh fitur terintegrasi dalam satu platform sehingga proses bimbingan, pemantauan progres, dan administrasi dapat dilakukan dengan lebih mudah, cepat, dan efisien. Aplikasi ini dapat diakses oleh **admin** dan **orang tua** sesuai dengan hak akses masing masing.

## Teknologi yang Digunakan
Aplikasi KahfiEdu dikembangkan menggunakan teknologi web modern. Frontend dibangun dengan React untuk menghasilkan antarmuka yang responsif dan interaktif, sedangkan backend menggunakan Express.js untuk menangani logika bisnis dan pengelolaan data. 

---

## Tujuan Pengembangan
Pengembangan KahfiEdu bertujuan untuk mendigitalisasi proses bimbingan belajar BTQ agar lebih efisien, transparan, dan mudah diakses. Dengan adanya sistem ini, diharapkan pihak pengelola, guru, dan orang tua dapat memantau serta mengelola aktivitas pembelajaran secara terintegrasi dalam satu platform.
